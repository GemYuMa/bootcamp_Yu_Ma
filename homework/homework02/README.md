# Homework 02 — Tooling Setup

This homework practices setting up a reproducible Python project environment and project scaffold. I created a dedicated Conda environment, installed the required Python packages, organized the project into standard folders for data, notebooks, source code, documentation, reports, and models, configured environment variables using a `.env` file, created a reusable configuration helper, verified the setup in Jupyter Notebook, and recorded the project dependencies in `requirements.txt`.
